億家 App v0.10.13.29 Feature Access Guard

這版把 SC / HQ 的即時功能開關，從「只改畫面」補成「真的阻止新操作」。

隨買跨店取 crossStoreRedeem 關閉時：
- 不可打開商品詳情開始新購買
- 不可加入購物車
- 不可進入結帳
- 不可建立店舖結帳訂單
- 不可用億家Pay建立隨買訂單
- 不可建立新的商品兌換 YD
- SC 在操作途中關閉功能時，App 會退出購物 / 結帳畫面

既有資料仍可查詢：
- 我的商品
- 訂單紀錄
- 商品使用紀錄
- 退貨 / 退款紀錄

點數同步 pointsSync 關閉時：
- 不顯示舊點數冒充最新點數
- 不可建立新的點數折抵碼
- 不可建立新的點數兌換

App enabled=false / maintenance=true 時：
- 新操作統一被阻止
- 繼續沿用既有服務暫停 / 維護遮罩

此版純前端，不用跑 SQL。
只需要上傳新的 index.html。
