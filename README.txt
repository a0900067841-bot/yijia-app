億家 App v0.10.13.24 Anybuy Product Checkout Ready

這版把「隨買跨店取 → 商品詳情 → 加入購物車」從開發提示整理成正式購物流程。

完成：
- 商品詳情購買按鍵改為「加入購物車」
- 加入後直接進購物車，不再跳開發測試提示
- 商品詳情會判斷正式可購買狀態：
  - enabled / active
  - 活動開始日
  - 活動結束日
  - 售價是否有效
- 尚未開賣、活動已結束、停用、價格未設定時：
  - 禁止加入購物車
  - 明確顯示原因
- 正常商品顯示「可加入購物車，結帳時再選擇付款方式」
- 移除舊的「付款功能尚未接通 / 開發測試模式」字樣
- 店舖結帳仍沿用既有正式待付款訂單 / QR Code 流程
- 不新增信用卡或線上金流處理

此版純前端，不用跑 SQL。
只需要上傳新的 index.html。
