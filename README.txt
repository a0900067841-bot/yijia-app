億家 App v0.10.13.27 Cart Catalog Validation

這版補上「購物車 → 結帳前」正式商品主檔驗證。

原因：
購物車存在 localStorage，使用者加入商品後，SC / HQ 可能已經修改：
- 售價
- 原價
- 組合數量
- 每人限購
- 活動開始 / 結束日期
- 商品啟用狀態
- 商品是否下架

本版完成：
- 進入購物車時重新讀 SC / HQ 正式隨買商品主檔
- 結帳前再驗證一次
- 自動更新購物車最新：
  - 商品名稱
  - 售價 / 原價
  - 每組數量
  - 效期
  - 購買上限
- 若限購數下降，購物車數量自動壓到最新上限
- 商品下架、停用、尚未開賣、活動結束、價格無效時：
  - 明確標示不可購買原因
  - 禁止進入結帳
- 價格或條件有變更時，會要求使用者先確認最新購物車內容

重要：
- 不相信 localStorage 裡的舊價格直接結帳
- 最終付款仍必須以後端正式驗證為準
- App 此版是結帳前 UI / 資料一致性保護

此版純前端，不用跑 SQL。
只需要上傳新的 index.html。
