億家 App v0.10.13.22 Wallet Refund Live Sync

這版把「億家Pay退款完成後 App 即時更新」正式接完整。

付款完成明細：
- 打開一筆已完成付款後，每 3 秒讀 app_get_yijiapay_pay_code_status()
- TM 執行部分退款 / 全額退款後：
  - 已退款金額即時更新
  - 剩餘可退款金額即時更新
  - 顯示「部分退款」或「已全額退款」
  - 更新正式錢包餘額
  - 更新完整交易紀錄
  - 更新首頁近期交易
  - 更新錢包帳本
  - 更新通知中心
- 關閉付款明細後停止輪詢

完整交易紀錄：
- 進入億家Pay交易紀錄後，每 10 秒重新讀正式付款歷史
- 有退款的交易會顯示：
  - 部分退款 / 已退款
  - 已退款金額
  - 剩餘可退款
- 狀態變更時同步更新錢包與通知

不新增退款邏輯。
退款仍由 TM 正式 tm_refund_yijiapay_payment() 執行，
App 只讀正式結果。

此版純前端，不用跑 SQL。
只需要上傳新的 index.html。
