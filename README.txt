億家 App v0.10.12.3 Pay Code Switch Guard

新增：
- 付款條碼 / QR Code 切換時加入防連點。
- 付款碼正在重新產生時：
  - 付款條碼按鈕暫時停用
  - QR Code 按鈕暫時停用
  - 🔄 暫時停用
  - 中央顯示「正在產生付款碼…」
- 避免快速連點造成同時送出多次付款碼建立請求。
- 完成後自動恢復按鈕。
- 仍維持正確規則：
  - 每次進入億家Pay → 新碼 + 60秒
  - 條碼/QR切換 → 新碼 + 60秒
  - 🔄 → 新碼 + 60秒
  - 到期 → 新碼 + 60秒
