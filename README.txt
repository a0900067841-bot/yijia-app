億家 App v0.10.13.12 Anybuy Return Completion Sync

這版把「隨買跨店取 → 退貨 / 退款」完成後的 App 即時同步正式收尾。

完成：
- App 建立退貨申請後，記住正式 returnCode
- 退貨結果頁每 3 秒讀取 HQ yj_app_return_requests
- 依正式 returnCode 找到該筆退貨申請
- 狀態為：
  - 申請中 / 退款中 / 退貨中 -> 顯示處理中
  - 退款完成 / 已退款 / 退貨完成 -> 自動顯示完成
  - 已拒絕 -> 顯示申請已拒絕
- 完成後自動更新：
  - 我的商品
  - 訂單管理
  - 商品使用紀錄
  - 通知中心
- 從「我的商品」重新打開既有退貨條碼時，也會重新監看正式退貨狀態
- 離開退貨結果頁後停止輪詢

不新增第二套退貨資料。
仍以既有 HQ yj_app_return_requests 與正式訂單 / 商品資料為準。

此版純前端。
不用跑 SQL，只上傳新的 index.html。
