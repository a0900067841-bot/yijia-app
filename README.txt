億家 App v0.10.13.28 SC App State Live Sync

這版把「SC / HQ App 設定 → 顧客 App」改成持續即時同步。

正式同步來源：
- yj_hq_app_settings
- yj_app_coupons
- yj_app_anybuy_products

同步時機：
- 會員登入後開始
- 每 30 秒自動同步一次
- App 從背景回到前景時也會立即同步

SC / HQ 修改後，App 可自動反映：
- App 服務停用
- 維護模式
- 公告文字
- 點數同步開關
- 隨買跨店取開關
- 億家Pay每月現金儲值上限
- 優惠券新增 / 修改 / 停用
- 隨買商品新增 / 修改 / 下架
- 商品價格、數量、限購、活動日期變更

如果使用者當下正在：
- 優惠券頁 → 立即刷新優惠券
- 隨買頁 → 立即刷新商品
- 購物車 → 重新驗證最新商品主檔
- 億家Pay儲值頁 → 更新最新儲值上限

登出後停止同步。

此版純前端，不用跑 SQL。
只需要上傳新的 index.html。
