億家 App v0.9.7 — 社群轉贈

新增：
- 手機留白時建立 YG 單次領取碼
- CODE128 條碼
- 分享領取連結
- 複製分享連結
- iOS/Android 原生分享選單（瀏覽器支援時）
- 領取頁掃描條碼
- 分享連結格式：?gift=YG...
- 點分享連結後，登入 App 會自動進「領取商品」並帶入 YG
- 領取成功後商品加入「我的商品」
- 同一 YG 成功領取一次後立即失效
- 禮物 / 轉贈紀錄會沿用 HQ / yj_app_gifts 自動更新

更新方式：
1. Supabase 執行 setup_v0_9_7_social_gift.sql
2. GitHub yijia-app 覆蓋 index.html

測試建議：
A. 原帳號轉贈時「手機留白」→ 確認轉贈
B. 應看到 YG、CODE128、分享連結
C. 用另一個帳號點分享連結或輸入/掃描 YG
D. 領取後確認「我的商品」、禮物紀錄、社群轉贈明細
E. 再次使用同一 YG 應失敗
